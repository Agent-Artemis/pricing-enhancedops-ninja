# pricing.enhancedops.ninja

Standalone pricing calculator for EnhancedOps.ninja covering all service lines:
- Stedi clearinghouse per-physician line-item breakdown
- EHR / RCM build pricing
- Dashboard Creator
- Ninja OS + SOP creator
- Agentic Voice (Retell AI)
- For A Full Life / Warrior Week

Stack: single HTML file, no dependencies, no build step.
Deploy target: Vercel, custom domain pricing.enhancedops.ninja
To update pricing: edit the JS constants in index.html.
